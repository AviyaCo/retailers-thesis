# Git backup versus full evidence backup

**Update 18 November 2026:** the code is now published in the public repository
[AviyaCo/retailers-thesis](https://github.com/AviyaCo/retailers-thesis) (branch `main`, contents of this folder at
the top level, written by [.archive_migration/git_code_backup.py](.archive_migration/git_code_backup.py)). The
private branch `backup/retailers-code-plots-20260930` of `AviyaCo/gold-srv2-homedir` (September and 17 November
commits) is kept unchanged as history and is no longer updated. How to rerun everything: [REPRODUCE.md](REPRODUCE.md).

The storage choice approved on 30 September 2026 is **Git for code, documentation
and plots; a local consolidated copy for full results/checkpoints for now**.
Git alone is therefore not a complete experiment backup.

## Publication

The publication script is [.archive_migration/git_code_plots.py](.archive_migration/git_code_plots.py).
It creates `backup/retailers-code-plots-20260930` as an independent root branch,
commits and pushes one directory group at a time, and verifies the final remote
commit. It does not change the working branch or its index. Its file-selection
plan is saved under the repository's Git metadata before committing.

Included: Python/shell source, Markdown/LaTeX documentation, configuration,
requirements references, and PNG/PDF/SVG/EPS/JPEG figures from the consolidated
folder, including historical archive copies. Included files must be smaller
than 100 MB; the entire selected payload must be below 1 GiB or publication
stops for review. These are backup guards, not experiment settings.

Excluded: raw result JSONs, model checkpoints, data arrays, logs, installed
dependencies, and navigation symlinks. Git documentation may reference those
excluded local evidence paths; restore the full folder to follow all links.
No historical numerical results are changed or regenerated by this operation.

The existing `WIP` history is **not** used as this branch's parent: it includes
oversized files, Python environments and a Gurobi license. Adding small commits
to that history would not make its push safe or acceptable to GitHub.

## Full evidence remains local

After the approved October 5 physical consolidation, keep this **entire
collection**, including [workspace](workspace/START_HERE.md), [archive](archive),
current comparison outputs and hidden migration inventories. Current experiment
trees live under workspace; archive aliases may share those canonical bytes.
The archive alone is no longer an independent backup. The earlier shipping
expansion preserved original folders and
existing archived bytes, verifies each added source/copy SHA256 pair, and records
source changes/gaps in its own dated status and JSONL journal. This is a
point-in-time copy, not an atomic filesystem snapshot.

An off-machine full-results destination has **not** been selected. The later
consolidation moved originals locally and removes only freshly verified duplicate
copies; it does not rely on Git for result recovery. Do not delete canonical
evidence on the assumption that Git contains its complete results. The dated
publication script above is historical and was not rerun by this consolidation.
See [BACKUP.md](BACKUP.md) for the original collection and restoration limits.
